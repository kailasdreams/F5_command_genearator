Take a UCS archive backup of the complete F5 configuration.
💾 UCS BACKUP CONFIGURATION
⚠️
Always take a UCS backup before and after any major configuration changes. UCS includes all configuration, SSL certificates, and license files.
Include private keys in backup
📋 BACKUP BEST PRACTICES
✓ Store UCS files off-box (SCP to backup server or download)
✓ Name backups with date stamp for easy identification
✓ Run tmsh save sys config before taking UCS
⚠ UCS restore will overwrite ALL configuration — use with caution
ℹ Schedule automated UCS via cron for production systems
